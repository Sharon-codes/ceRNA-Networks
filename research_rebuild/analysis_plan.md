# Prospective rebuild specification

Frozen 2026-09-07, after source/PDF/metadata audit and before corrected graph/dropout outcomes. This is not preregistration of the original study. Exact UTC freeze and SHA-256 are in manifests/plan_freeze.json.

Question: Does empirical edge betweenness provide reproducible additional information about retained-edge dropout after accounting for threshold proximity and correlation-estimation uncertainty? Primary estimand is descriptive conditional prediction across the fixed retained edge universe, not a causal EBC effect or an equivalence test. No scientifically justified negligible-effect bound is available; no equivalence claim will be made.

Primary cohorts: exact tissue=Carcinoma in GSE115513; diagnosis=breast cancer and tissue=serum in GSE73002. Carcinoma subjects are unique; serum sample titles are unique but independent patient identity remains assumed. Preserve all eligible arrays; no outcome-driven exclusions. Repeated recorded patients, if introduced, must be sampled as blocks; the selected carcinoma set has none.

Primary features: complete-case, nonconstant probes, ranked by median absolute deviation on the supplied processed scale; stable tie-breaking by original row order. Use up to 500, explicitly retaining zero-MAD but nonconstant probes only if needed. The original preprocessing selected on log2(x+1) in tissue; evaluate that as a targeted historical-selection sensitivity. No further log transform of serum; no imputation or zero substitution. Upstream tissue zeros and serum detection-floor substitution are retained and documented. Probe annotations remain at their platform versions; ambiguous mappings are excluded from named-miRNA interpretation, not silently collapsed in the primary probe network.

Primary graph: unsigned abs(Spearman r), full fixed selected-node graph, undirected, zero diagonal, unique upper-triangle pairs. Quantile threshold uses linear interpolation at 1-density over all p(p-1)/2 pairs. Include all threshold ties; report achieved density, tie multiplicity, full and GCC counts. EBC is exact normalized NetworkX edge betweenness on the declared graph, with actual bridge status recorded separately. Margin=abs(r)-theta for retained edges; retain signed margin for the absent pair universe. Positive-only hard edges and max(r,0)^beta form the sign sensitivity.

Conditional resampling: 1,000 independent streams per cohort, sample rows (known patient units for tissue, assumed independent arrays for serum), rerank within every draw. Freeze feature identities, cutoff, graph predictors and focal nodes. Store upper-triangle float64 correlation blocks with validated input/config/core-code hash and atomic manifests; never treat undefined correlations as zero. Replicates containing undefined selected-probe correlations are failures, excluded with counts. Correlation bootstrap SD supplies the uncertainty-scaled margin; exclude near-zero SD (<1e-10) explicitly from that model. No Pearson/Fisher approximation is used for the empirical Spearman model.

Models: linear distance; linear distance plus raw EBC; natural cubic spline distance with 4 df; corresponding log1p(EBC/median-positive-EBC) addition; spline on margin/bootstrap-SD, with and without transformed EBC. EBC scaling constants and spline bases saved. No interactions in the primary comparison. Fits use binomial counts as conditional descriptive estimates. Model SE/CI from resampling complete replicate vectors quantify only Monte Carlo error, preserving all cross-edge dependence induced by each draw. For linearized estimates use the replicate-score sandwich; test nonlinear robustness against direct replicate-vector refits in a pilot. Report probability contrasts at within-distance-bin observed EBC quartiles, not negative or unsupported centralities. Calibration/residual and binomial deviance are descriptive, not independent-edge hypothesis tests.

Predictive evaluation: deterministic disjoint half-cohort splits, select features and cutoff only in reference half. Fit dropout models to 250 reference-half bootstrap draws; evaluate on 250 independent validation-half draws for the same feature/pair universe and frozen reference graph predictors. Validation correlations may be below reference threshold: those remain in the response. Correlation SD estimated in reference data only. Report paired replicate-level log-loss differences and their Monte Carlo intervals; no random edge splitting and no claim that these intervals capture biological generalization uncertainty. Also quantify edge selection and hub priorities on the direct held-out half. Split outputs are internal validation, not external biological replication.

Sensitivity design (targeted, not Cartesian): same primary 1,000 correlation draws reused across densities 1%, 2.5%, 5%, 10%, unsigned/positive sign, full/GCC EBC restrictions, soft beta=1,2,4,6,8,12. Feature 250 and 1,000, log1p tissue selection, 50%/75% sample sizes and serum <=20% missingness with median imputation each use 200 draws and are exploratory. The imputation sensitivity is explicitly distinct from the complete-case primary. Full procedure: 100 outer patient/array draws reselect features and cutoff, then compare retained identities and top-20 hubs; changing feature/pair universes are summarized with set overlap, not paired edge coefficients. Colon/rectum and serum TR_B/TS_B strata are targeted heterogeneity diagnostics; no automatic batch adjustment. These stratum labels do not establish laboratory batches.

Hard/soft: same resamples, all fixed nodes, same sign. Full compatible soft network versus hard degree, and a fixed baseline hard-edge support with soft weights on that same support. Every neighbor ranges over the full selected-node set; additionally summarize the fixed baseline GCC focal nodes. Use sample SD (ddof=1) / mean; zero mean is undefined and counted, never epsilon-repaired. Save node means/CVs, ratio-of-mean-CV reduction and nodewise reductions separately. Monte Carlo intervals resample complete replicate vectors; no node bootstrap claiming biological uncertainty. Primary biological application: reproducibility of top-20 miRNA/probe hub prioritization and ranking. No pathway or ceRNA mechanism claim. Report hard/soft top-20 overlap and degree/strength rank stability, resolving ties deterministically and disclosing them.

Historical reproduction: isolated outputs, exact RandomState(42), original log selection, thresholds .819/.958, positive hard/GCC EBC, unsigned beta=6 full-neighbor strengths, 1,000 draws and ddof=0. Recover one-endpoint clustered, HC0 and nominal SE; repeat one-endpoint clustering under 100 deterministic node relabelings. Historical coefficients and inference must not be mixed with corrected model output.

Population inference: profile a 20-outer x 100-inner complete-estimator pilot, including feature/cutoff reselection, logging runtime and failures. The outer estimand is the EBC coefficient per within-network transformed-EBC SD, a distribution of procedure-dependent effects rather than identical raw-unit effects. This pilot is not automatically a confidence interval. Expression-level simulations test Spearman bootstrap-SD and percentile-CI coverage with known population correlations, and graph/hub recovery with known PSD latent-factor covariance. Eight scenarios, 200 independent datasets each, 200 bootstraps each. Continuous Gaussian/copula cases use the exact bivariate normal Spearman target; ties/outliers/batch scenarios have altered targets and will not be assigned a false known target. A known zero adjusted-EBC coefficient is NOT implied by an expression DGP. EBC false-positive/power/coverage remains unresolved unless an independently justified target can be established; no biological p-values from conditional fits. If pilot or calibration cannot justify population inference, retain conditional/descriptive conclusions and state that explicitly.

Simulation precision: binomial Wilson intervals on coverage/recovery proportions; 200 datasets yield at most about 3.5 percentage points SE. Report this limitation. Bootstrap precision: compare independent halves and prefixes B=100,250,500,1000, estimated MCSE and complete-replicate split differences. Fixed B=1000 gives maximum edge MCSE .01582; do not interpret increased B as additional patients.

External validation: inspect first candidate GSE39845 selected from official GEO for colorectal tissue context before outcomes. Require at least 30 independent carcinoma specimens, traceable mature-miRNA mapping and reasonable shared coverage (>=100). If it fails, document the exact cause and continue an outcome-blind official-GEO search; do not select for favorable network results. Any external application uses the discovery-derived feature set/sign/power, declared mapping and density rules.

Resource limits: six wall hours and 12 GB caches on a 16 GB, 12-logical-CPU Windows host. Profile before expensive jobs. Stages resumable; all prespecified stages receive completed/failed/blocked status. Production run completion requires output inspection and tests, not script creation. Amendments are appended with timestamp/reason and outcome-exposure status; original results are preserved.
