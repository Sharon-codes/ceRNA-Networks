# Amendments

None at initial plan freeze. The following implementation/scope clarifications were recorded retrospectively on 2026-09-07 after execution, with exposure stated explicitly. The original plan/config and their freeze hashes are retained unchanged.

1. A synthetic fixed-cutoff test found empty edge indices inferred as floating point. Explicit integer indices fixed the implementation before production bootstrap outcomes. All original ten scientific tests then passed.
2. Simulation profiling showed repeated scalar library thread-control overhead. The preliminary run was stopped after progress logging; no simulated observations were used to tune scenarios. Batched within-resample rankdata and matrix multiplication replaced scalar execution using the same index stream and DGP. A test compares every batched matrix against scipy.stats.spearmanr on tied resamples. The preliminary log remains `logs/simulations.log`; completed runs are in `logs/simulations_vectorized.log`. Scenarios, counts and seeds did not change.
3. The 1000-feature tissue setting yielded zero valid full-matrix bootstrap draws because rare probes became constant. A post-failure continuation fix records this setting as failed, skips its impossible regression, and continues other prespecified settings. The failed sensitivity receipt remains in `logs/preserved_pre_fix/`; no rare probe was excluded to recover a preferred result.
4. The initial nodewise percentage calculation returned infinities for nodes with zero hard CV. Those ratios are now undefined and excluded only from the explicitly counted nodewise-ratio summary; all replicate/node data and ratio-of-mean-CV summaries remain intact. Previous tables remain in `logs/preserved_pre_fix/`. Whole-replicate percentile ranges for the highly nonregular all-node summaries are diagnostic Monte Carlo ranges, not coverage-validated intervals; rare/zero means can cause bias. GCC focal comparisons are also descriptive.
5. Before examining held-out prediction results, validation probes with missing/constant values were explicitly removed only from the evaluated reference-edge universe. The reference feature selection, graph, model and training sample remained fixed. For serum, 438/500 reference-selected probes and 2474/3119 reference edges were evaluable; no missing validation correlations were replaced with zero. Loss intervals currently reflect validation MC error and omit reference-fit/population uncertainty.
6. The external search expanded beyond the initial candidate under the plan's outcome-blind eligibility rule. GSE39845 had only three cancer-tissue arrays, GSE68377 seven, and GSE128446 eighteen tumor arrays; GSE41655 provided 33 adenocarcinoma arrays. The external parser was generalized to handle metadata keys appearing on different characteristic rows without substring diagnosis matching. Official alias mapping and a 204-node intersection were frozen before computing transfer results. Independent patient linkage remains unavailable; this is an exploratory independent-study transfer with assumed array independence.
7. Population EBC inference was not promoted to large nested production after the 20x100 pilots. The EBC null/alternative target-calibration requirement remains unresolved. Correlation simulations cannot be substituted for EBC false-positive rates or power. No choices were made to recover historical p-values or the 84% claim.
